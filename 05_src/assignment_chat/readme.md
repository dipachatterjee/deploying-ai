# Assignment Chat App

A chatbot that can answer questions about the weather, give you bird facts, or give you historical facts.  

## Features

- **Weather:** Get the current weather in any city.  
- **Bird Facts:** Learn interesting facts about birds (aka tiny dinosaurs).  
- **History Facts:** Get interesting historical facts.  

---

## Setup

1. Make sure you have Python 3.10+ installed.  
2. Clone this repository.
3. Make sure you have an API_GATEWAY_KEY in your .secrets
4. Open a terminal (e.g. git bash)
5. Nagivate to './05_src'
6. activate using 'python -m assignment_chat.app'
7. Click on the generated local URL
7. Enjoy!
